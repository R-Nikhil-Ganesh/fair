# Sample Datasets

These CSVs are included for local development only.
In production, they are stored in Firebase Storage at gs://{bucket}/sample-datasets/

- german_credit.csv — 1000 rows, columns: age, sex, credit_amount, duration, credit_risk
- compas_subset.csv — 500 rows (subset), columns: race, sex, priors_count, two_year_recid
- adult_income_subset.csv — 5000 rows (subset), columns: age, workclass, education,
  marital_status, occupation, race, sex, hours_per_week, income
